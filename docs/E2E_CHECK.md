# Наскрізна перевірка (виконано 2026-10-21)

Середовище: Windows 11, `runserver` на `127.0.0.1:8000` (БД для розробки — SQLite), `manage.py run_worker`,
Vite dev-сервер із проксі `/api`. Ollama **не встановлена** (свідомо перевірявся сценарій недоступного ШІ).

Локальний тестовий обліковий запис (існує лише в `Backend/db.sqlite3` цієї машини, не для production):
`e2e@worldweaver.test` / `Ww-e2e-Test-2026!`.

Консоль браузера: лише очікувані HTTP-помилки (403 до входу, 400 на слабкий пароль, 500 з кроку 4). JS-помилок немає.

Не перевірялось у браузері: завантаження/вивантаження DOCX і портретів (покрито backend-тестами),
реальний глибокий аналіз з Ollama (немає моделі в середовищі).
